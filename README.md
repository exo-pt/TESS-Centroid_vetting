# TESS centroid_vetting
# Overview

`TESS-Centroid_vetting` provides photometric centroid offset analysis for vetting exoplanet candidates identified in TESS (Transiting Exoplanet Survey Satellite) data.<br/>
It was inspired by the graphical representation of the centroid in the Data Validation (DV) reports of Threshold Crossing Events (TCEs) produced by the TESS Science Processing Operations Center (SPOC) pipeline<br/>
The centroid representation allows identifying the source of the dips in a light curve, discarding potential false positives and identifying possible sources of contamination.<br/>
It is an open-source Python package that can analyze any TESS Target Pixel File.

![Img](https://raw.githubusercontent.com/exo-pt/TESS-Centroid_vetting/main/tesscentroidvetting_example.png)

# Method

The method is similar to the centroid offset analysis in TESS SPOC TCE DV reports, which measures centroids using difference imaging with PRF-based (pixel response function) centroid fitting.

`TESS-Centroid_vetting` lets users customize some parameters to handle edge cases, including:

- **Pixel masking:** ignores selected pixels during calculation, which helps avoid pixels that could skew the results (e.g., a nearby variable star).
- **In-transit / out-of-transit duration:** can be customized to avoid problematic cadences.

#### Current limitations (v1.4.0):

- The centroid uncertainties are not available.
- Multi-sector centroid fitting is not available.

Comparability with TESS TCE DVs: it has been evaluated in an ad-hoc basis that the result from `TESS-Centroid_vetting` is comparable to TESS TCE DVs. However, it has not been systematically evaluated yet.

## Installation
Since version 1.2.0, a package is available at PyPi.<br>
So, the simplest way of installing TESS-Centroid_Vetting is using pip:

`pip install tesscentroidvetting`

## Dependencies:
- numpy
- matplotlib
- astropy
- astroquery
- scipy
- lightkurve
- ipywidgets - only needed if interact=True in show_transit_margins()
